Conversational Clustering for Service-Desk Tickets

LLMs Clustering FastAPI React Docker

Team project developed for the Large Scale AI Systems course. We built a working local application that allows users to explore and iteratively refine clusters of internal helpdesk tickets through natural-language instructions.

Working local prototype · LLM + embeddings + K-Means/GMM

The system combines an LLM-based intent parser with embeddings and clustering methods including K-Means and GMM. User instructions are converted into structured constraints, allowing the clustering to be recomputed and progressively refined through feedback.

System Highlights

  • Conversational interface for exploring and refining ticket clusters
  • LLM-based conversion of natural-language requests into structured constraints
  • Embedding-based clustering using K-Means and Gaussian Mixture Models
  • React + Vite frontend connected to a FastAPI backend
  • Dockerized local setup with automated tests and documented API endpoints

Team project · Working local prototype · Shared team repository · Not publicly available

Collaboration: developed collaboratively by a two-person team, with both members contributing across system design, AI pipeline, implementation and experimentation.

Compositional Image Retrieval with CLIP

Deep Learning CLIP Multimodal AI PyTorch Model Evaluation

Team project developed for the Deep Learning course, focused on compositional image retrieval with CLIP on the CelebA dataset. Starting from a training-free CLIP arithmetic baseline, we explored different strategies for combining textual conditions, visual attribute directions, and the reference image embedding.

Recall@10: 0.116 → 0.174 · +49.6% relative improvement

We compared gated text fusion, visual-direction retrieval, hybrid text-visual fusion, prompt ensembling, and reliability-based variants, selecting hyperparameters on the validation split and evaluating the final methods on the held-out test set.

Results

  • Improved Recall@10 from 0.116 for the CLIP baseline to 0.174
  • Achieved approximately 49.6% relative improvement over the baseline
  • Best performance obtained by combining visual directions with a prompt-difference text representation
  • Identified saturation in later fixed-weight fusion strategies, suggesting limits of handcrafted global weighting

Team project · Experimental notebook available for download

Collaboration: developed collaboratively by a three-person team, with contributions shared across methodology design, implementation, experimentation and evaluation.
