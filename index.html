Designing and Evaluating Transformer-Based Pipelines for Urgency Detection in Financial Product Complaints

Data preprocessing NLP tasks BERT fine-tuning

This thesis explored how natural language processing can support the prioritization of consumer complaints by identifying signals of urgency within complaint texts. Starting from a real-world dataset of financial complaints, the project focused on designing and evaluating a complete NLP pipeline that combines complaint classification and sentiment analysis to derive an urgency indicator. The workflow began with data preprocessing and dataset splitting, followed by training transformer-based models for complaint-type classification. The models were fine-tuned and evaluated on an HPC cluster using a Slurm-based scheduler to enable systematic experimentation and checkpoint selection. In parallel, a sentiment analysis module compared multiple pretrained transformer models to extract sentiment signals from the complaints. The outputs of both tasks were then combined to produce an urgency metric, illustrating how different NLP components can be integrated into a practical decision-support pipeline.

The project emphasized not only model performance but also pipeline structure, evaluation logic, and the practical applicability of NLP systems in complaint-management contexts.

  • Data preprocessing - cleaned and split the complaint dataset into training and test sets
  • Text representation - tokenized complaints texts using BERT tokenizers
  • Complaint classification - fine-tuned BERT and FinBERT models to predict complaint types
  • Model experimentation - ran training jobs on an HPC cluster using SLURM
  • Sentiment analysis - compared multiple transformer models (FinBERT-tone, Twitter RoBERTa, multilingual BERT, DistilRoBERTa)
  • Urgency Estimation - combined classification outputs and sentiment scores to derive an urgency metric
